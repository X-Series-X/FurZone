# Fursuit & Therian Gear Price Guide

A simple, open website that lists **typical prices** and useful **websites** for:

- Fursuits (heads, partials, fullsuits)
- Therian masks
- Tails, paws, and related accessories

## Live Site

Once you push this to a GitHub repository and enable **GitHub Pages**, the site will be available at:

`https://yourusername.github.io/your-repo-name/`

### How to enable GitHub Pages

1. Create a new repository on GitHub (or use an existing one).
2. Upload the files in this folder (`index.html`, `styles.css`, `README.md`).
3. Go to **Settings → Pages**.
4. Under **Source**, select **Deploy from a branch**.
5. Choose the `main` (or `master`) branch and `/ (root)`.
6. Save. After a minute or two the site will be live.

## What’s included

- Clean, modern dark theme
- Price range tables for fursuits and Therian gear (approximate 2025–2026 values)
- Links to popular places to buy (The Dealers Den, Etsy, Amazon, etc.)
- Practical tips for buyers
- Fully responsive (works on phone and desktop)
